# Microsoft Azure security documentation

Welcome to the open-source documentation for [Microsoft Azure](https://azure.microsoft.com) security services. This repository holds the source for the following docsets on [Microsoft Learn](https://learn.microsoft.com/azure/):

- [Azure Attestation](https://learn.microsoft.com/azure/attestation/)
- [Azure Cloud HSM](https://learn.microsoft.com/azure/cloud-hsm/)
- [Azure Confidential Ledger](https://learn.microsoft.com/azure/confidential-ledger/)
- [Azure Dedicated HSM](https://learn.microsoft.com/azure/dedicated-hsm/)
- [Azure Key Vault](https://learn.microsoft.com/azure/key-vault/)
- [Azure Managed HSM](https://learn.microsoft.com/azure/key-vault/managed-hsm/)
- [Azure Payment HSM](https://learn.microsoft.com/azure/payment-hsm/)

To understand how you can contribute to the Microsoft Azure security documentation, review this README file.

## Getting started

Contributing to open source is more than just providing updates. It's also about letting us know when there's an issue. To learn more, read our [Contributing guidance](CONTRIBUTING.md).

### Prerequisites

You decided to contribute. That's great! To contribute to the documentation, you need a few tools.

#### GitHub

Contributing to the documentation requires a [GitHub account](https://github.com/). If you don't have an account, follow the instructions for [GitHub account setup](https://learn.microsoft.com/contribute/get-started-setup-github) in our contributor guide.

#### Tools

To install the necessary tools, follow the instructions for [Install content authoring tools](https://learn.microsoft.com/contribute/get-started-setup-tools) in our contributor guide.
